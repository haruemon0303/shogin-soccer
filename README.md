# SHOGIN サッカー

将棋×サッカーの完全情報・運なし・ターン制タクティカルゲーム

## 概要

「SHOGIN サッカー」は、将棋の駒の動きとサッカーのゲーム性を融合した、2人対戦型のターン制戦術ゲームです。
自分の駒を動かしてボールを相手ゴールに運び込むか、相手の玉（GK）を捕獲すると勝利です。

## プレイ方法

GitHub Pagesで公開：`https://<your-username>.github.io/shogin-soccer/`

ブラウザで `index.html` を開くだけで遊べます（外部サーバ不要）。

## ゲームルール（MVP版）

### 盤面

- **9×9マス**の盤面を使用
- **先手（青）**：盤面上側からスタート
- **後手（赤）**：盤面下側からスタート

### ゴール

- **先手ゴール**：最上段（row 0）の中央3マス（列3, 4, 5）
- **後手ゴール**：最下段（row 8）の中央3マス（列3, 4, 5）

### 初期配置

**先手（青）：**
- 玉（GK）：(0, 4)
- 飛車（FW）：(2, 4)
- 角（MF）：(2, 2)
- 歩（FW）：(3, 3), (3, 4), (3, 5)

**後手（赤）：**
- 玉（GK）：(8, 4)
- 飛車（FW）：(6, 4)
- 角（MF）：(6, 6)
- 歩（FW）：(5, 3), (5, 4), (5, 5)

**ボール：**
- 初期位置：中央マス (4, 4)

### 駒の種類と動き

駒の動きは将棋に準拠します（自陣から相手陣方向を「前」とする）：

- **玉（GK）**：全方向に1マス
- **飛車（FW）**：縦横に何マスでも直進
- **角（MF）**：斜めに何マスでも直進
- **歩（FW）**：前方に1マス

### ボールの扱い

1. **保持**：自分の駒がボールのあるマスに移動すると、その駒がボールを保持します
2. **奪取**：相手がボールを保持している駒を捕獲すると、ボール保持者が切り替わります
3. **パス**：ボール保持中の駒は、その駒が移動できる範囲内の空きマスにボールだけを移動できます（駒は動かない）
   - パス先が相手の駒のマスは不可
   - パス先に自分の駒がいる場合、その駒がボールを受け取ります

### ターン制

- 各プレイヤーは手番ごとに以下のいずれか1回を実行：
  1. **駒を移動**：自分の駒を合法手で移動
  2. **パス**：ボール保持中の駒からボールだけを移動

### 駒の捕獲

- 相手の駒がいるマスに自分の駒を移動させると、相手の駒を捕獲できます
- **MVP版では持ち駒システムなし**（捕獲した駒は盤面から除去されます）

### 勝利条件

以下のいずれかを達成すると勝利：

1. **ゴール達成**：自分がボールを相手のゴールマスに運び込む
2. **玉（GK）を捕獲**：相手の玉を捕獲する

## 操作方法（スマホ対応）

1. **駒の選択**：自分の駒をタップして選択
2. **移動先の選択**：ハイライトされた移動可能マスをタップ
3. **パス**：ボール保持駒を選択後、「パスモード」ボタンをタップしてパス先を選択
4. **選択解除**：「選択解除」ボタンで選択をキャンセル

## MVP仕様（現在のバージョン）

このバージョンは最小限で遊べるMVP（Minimum Viable Product）です。

**実装済み機能：**
- 9×9盤面とゴール判定
- 基本的な駒（玉、飛車、角、歩）
- 駒の移動と捕獲
- ボールの保持・パス・奪取
- ターン制の手番管理
- 勝利判定（ゴール / 玉捕獲）
- スマホ対応UI（タップ操作）

**未実装（拡張予定）：**
- 持ち駒システム（捕獲した駒を打つ）
- 成り（敵陣で駒が成る）
- オフサイドルール
- 初期フォーメーション選択
- リプレイ / undo機能
- 対CPU（AI）
