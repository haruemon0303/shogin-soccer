# SHOGIN サッカー

将棋×サッカーの完全情報・運なし・ターン制タクティカルゲーム

## 概要

「SHOGIN サッカー」は、将棋の駒の動きとサッカーのゲーム性を融合した、2人対戦型のターン制戦術ゲームです。
駒を動かしてボールを相手ゴールに運び込むと勝利。オウンゴールに注意！

### 3行まとめ

1. **将棋の駒を動かしてボールを相手ゴール（端中央3マス）に運ぶ**
2. **駒をタップ → 青=移動、緑/金=パス、赤=捕獲、紫=ベンチから投入、敵陣で成り**
3. **捕獲した駒はベンチに入り投入可能（簡易オフサイド・二歩あり）。AI対戦もあり**

## ゲームルール（MVP版）

### 盤面

- **9×9マス**の盤面を使用
- **先手（青）**：盤面上側からスタート
- **後手（赤）**：盤面下側からスタート

### ゴール

- **先手ゴール**：最上段（row 0）の中央3マス（列3, 4, 5）
- **後手ゴール**：最下段（row 8）の中央3マス（列3, 4, 5）

### 初期配置

ゲーム開始時に2種類の配置から選択できます：

**A) 将棋配置（標準）**
- 標準的な将棋の駒配置を採用
- 各プレイヤー：玉1・飛1・角1・金2・銀2・桂2・香2・歩9

**B) サッカー配置（4-4-2風）**
- 中央寄せのサッカーフォーメーション
- 各プレイヤー：玉1・飛2・角1・金2・銀2・歩9

**ボール：**
- 初期位置：中央マス (4, 4)

### 駒の種類と動き

駒の動きは将棋に準拠します（自陣から相手陣方向を「前」とする）：

- **玉（GK）**：全方向に1マス
- **飛車（FW）**：縦横に何マスでも直進
- **角（MF）**：斜めに何マスでも直進
- **金（DF）**：前3方向と左右と後ろ（斜め後ろ以外）
- **銀（MF）**：前3方向と斜め後ろ2方向
- **桂馬（FW）**：前2マス先の左右1マス
- **香車（DF）**：前方に何マスでも直進
- **歩（FW）**：前方に1マス

**駒の凡例**：ゲーム画面の盤面下に「駒の種類（タップで開く）」があり、各駒の動きを確認できます。

### ボールの扱い

1. **保持**：自分の駒がボールのあるマスに移動すると、その駒がボールを保持します
2. **奪取**：相手がボールを保持している駒を捕獲すると、ボール保持者が切り替わります
3. **パス（視線ベース）**：ボール保持中の駒は、以下の条件でパスできます
   - **8方向**（縦/横/斜め）の直線上にパスできます
   - **視線が通る**：パスの経路に駒がない（途中のマスに味方/敵の駒があればブロックされる）
   - **味方駒へパス**：味方駒がいるマスへパス可能（金枠で強調表示）
   - **スルーパス**：空きマスへもパス可能（緑マスで表示）
   - **注意**：自分のゴールへのパスはオウンゴールになります

### ターン制

- 各プレイヤーは手番ごとに以下のいずれか1回を実行：
  1. **駒を移動**：自分の駒を合法手で移動
  2. **パス**：ボール保持中の駒からボールだけを移動
  3. **交代投入（ドロップ）**：ベンチの駒を盤面に配置

### 駒の捕獲とベンチ（交代投入）

- 相手の駒がいるマスに自分の駒を移動させると、相手の駒を捕獲できます
- **捕獲した駒はベンチ（持ち駒）に追加されます**
- ベンチの駒は後で盤面に投入できます（将棋の「打つ」＝サッカーの「交代投入」）

### 交代投入（ドロップ）のルール

- **ドロップ可能な駒**：ベンチにある駒（捕獲した相手の駒）
- **配置場所**：空きマスに配置可能（以下の制限あり）
  - **簡易オフサイド**：相手陣の最深部2行にはドロップ不可
    - 先手：row 7, 8（最下段2行）にドロップ不可
    - 後手：row 0, 1（最上段2行）にドロップ不可
  - **二歩禁止**：同じ列に既に自分の歩がある場合、その列に歩をドロップ不可
- **配置後の動き**：配置した駒は自分の駒として通常通り動けます（成りはリセットされる）
- **手番の扱い**：配置した時点で手番終了
- **操作方法**：
  1. ベンチの駒をタップ → ドロップモードに切り替わる
  2. 空きマス（紫色でハイライト）をタップ → 駒を配置
  3. 禁止された配置を試みるとトースト通知が表示されます

### 成り（駒の昇格）

駒が敵陣（盤面の最深部3行）に侵入した際、その駒を成ることができます：

- **敵陣の定義**：
  - 先手：row 6, 7, 8（最下段3行）
  - 後手：row 0, 1, 2（最上段3行）
- **成り可能な駒と成り後の動き**：
  - **歩 → と金**：金と同じ動き（前3方向・左右・後ろ）
  - **香 → 成香**：金と同じ動き
  - **桂 → 成桂**：金と同じ動き
  - **銀 → 成銀**：金と同じ動き
  - **角 → 馬**：角の動き + 前後左右1マス
  - **飛 → 龍**：飛の動き + 斜め1マス
  - **金・玉**：成ることができません
- **成り判定**：
  - 敵陣に侵入した時点でダイアログが表示されます
  - 「成る」または「成らない」を選択できます（任意）
  - AIは基本的に成りを選択します
- **UI表示**：成った駒は右下に金色のドットが表示され、駒の文字が変わります（例：歩→と）
- **注意**：捕獲された駒はベンチで元の駒に戻ります（成りはリセット）

### 勝利条件

**勝利条件は「ゴール」のみ**です：

1. **ゴール達成**：ボールを相手のゴールマス（相手側端の中央3マス）に運び込むと勝利
2. **オウンゴール**：ボールが自分のゴールマスに到達すると敗北（相手の勝利）
3. **玉の捕獲**：玉を捕獲しても勝利にはなりません（駒の捕獲は可能ですが勝敗に影響なし）

## 対戦モード

### ローカル2人対戦

同じ端末で2人で対戦できます。先手（青）と後手（赤）を交互に操作します。

### AI対戦モード

コンピューター（後手・赤）と対戦できます。AIはヒューリスティック評価に基づいて手を選びます：

- **目標**：ボールを相手ゴールに近づける
- **防御**：オウンゴールを避け、自分のゴールからボールを遠ざける
- **戦術**：ボール奪取や駒の捕獲を行う
- **思考時間**：約0.3秒で手を決定

## 操作方法（スマホ対応）

### 基本操作

1. **駒の選択**：自分の駒をタップして選択
2. **移動**：青マスをタップして移動（または「移動」ボタン）
3. **パス**：緑マスをタップしてパス（または「パス」ボタン）
   - 金枠：味方駒へのパス
   - 緑マス：空きマスへのスルーパス
4. **捕獲**：赤枠の相手駒をタップして捕獲
5. **交代投入**：ベンチの駒をタップ → 紫マスをタップして配置
6. **選択解除**：「選択解除」ボタンで選択をキャンセル

### iPhoneでの操作例（3ステップ）

#### 例1：ボールを取得して前進
1. **中央の⚽をタップ** → 近くの自分の駒を選択
2. **ボールのマスをタップ** → ボールを取得（⚽マークが駒に付く）
3. **青マスをタップ** → 相手ゴール方向へ移動

#### 例2：ボールをパス
1. **⚽マークのついた自分の駒をタップ** → ボール保持駒を選択
2. **「パス」ボタンをタップ** → パスモードに切り替え（緑マスが表示される）
3. **緑マスをタップ** → 味方の駒や空きマスにパス

#### 例3：相手駒を捕獲
1. **自分の駒をタップ** → 駒を選択
2. **赤枠の相手駒を確認** → 捕獲可能な駒が赤枠で表示される
3. **赤枠の駒をタップ** → 相手駒を捕獲して移動（ベンチに追加される）

#### 例4：ベンチから駒を投入
1. **ベンチの駒をタップ** → ドロップモードに切り替わる
2. **紫マスを確認** → 配置可能な空きマスが紫色で表示される
3. **紫マスをタップ** → 駒を配置して手番終了

### 色分けガイド

- **青マス**：移動可能な空きマス
- **緑マス**：パス可能な空きマス（スルーパス）
- **金枠**：パス可能な味方駒（味方へのパス）
- **赤枠**：捕獲可能な相手駒
- **紫マス**：ベンチから配置可能な空きマス
- **⚽マーク**：ボール保持者
